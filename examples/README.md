# Examples

This directory contains example files and templates that can be used alongside the skills in this repository.

## Contents

| File | Description | Related Skill |
|---|---|---|
| `external-genomes-template.txt` | Template for external genomes input file | Skill 04 (Pangenomics) |
| `internal-genomes-template.txt` | Template for internal genomes input file | Skill 04 (Pangenomics) |
| `metagenomics-config-template.json` | Template for metagenomics workflow config | Skill 08 (Snakemake) |

## Usage

Copy the template files to your project directory and modify them as needed:

```bash
cp external-genomes-template.txt /path/to/your/project/external-genomes.txt
# Edit the file with your genome paths
```
